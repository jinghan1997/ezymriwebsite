# ezyMRI static website

A responsive, static recreation of [ezymri.com](https://ezymri.com/) built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Publish with GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing this project (usually `main`) and the `/ (root)` folder, then save.

The contact form opens the visitor's default email app because GitHub Pages does not provide server-side form processing.
